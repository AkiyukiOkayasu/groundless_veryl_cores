AdatTx

ADAT TXトップモジュール

8ch 24bit PCMをADATフレームへ変換し、NRZI信号として出力する。 送信パイプラインは以下の3段で構成される。

  1. tx_frame_builder
    • frame_clk立ち上がりをトリガに256bit ADATフレームを構築
  2. tx_bit_serializer
    • 256bitフレームをMSB-firstでシリアル化
    • ADAT_FAMILYに応じて44.1kHz系/48kHz系のビット周期を選択
  3. tx_nrzi_encoder
    • シリアルビットをNRZIへ変換してadatへ出力

Parameters

CLK_FREQ u32 システムクロック周波数 [Hz]
ADAT_FAMILY AdatFamily ADATビットレートファミリー (1'b0=F44K1[44.1kHz系], 1'b1=F48K[48kHz系])

Ports

clk input clock システムクロック (50MHz)
rst input reset
frame_clk input logic 外部フレームクロック立ち上がりで新規フレーム送信開始
channels input logic<24> [8] 8ch 24bit PCM入力
smux_active input bbool S/MUX有効フラグ入力
adat output logic ADAT NRZI出力
frame_done output logic 256bitフレーム送信完了パルス

Aes3ChannelStatusCrc

AES3 professional channel statusのCRC-8を計算する。

CRC対象はblock先頭からの184bitで、LSB first・初期値FFh・ 生成多項式x^8+x^4+x^3+x^2+1（反転表現B8h）を用いる。 1クロックに1bitを処理するため、50MHz動作でも回路規模を抑えられる。

Ports

HpfShiftSigned

ビットシフトによる一次ハイパスフィルタ (符号付き版) LPFの出力を入力から減算してHPFを構成: y[n] = x[n] - lpf[n] 内部でLpfShiftSignedをインスタンスして使用

カットオフ周波数の近似: fc ≈ fs / (2π * 2^SHIFT) 例: fs=48kHz, SHIFT=8 → fc ≈ 30Hz

SHIFT値が大きいほどカットオフ周波数が低くなり、より多くの低域を通過させる。

Parameters

DATA_WIDTH u32 入出力データ幅
SHIFT u32 シフト量 (1以上)。大きいほど低いカットオフ周波数

Ports

enable input bbool イネーブル信号 (trueでフィルタ更新)
x input signedlogic 入力サンプル (符号付き)
y output signedlogic フィルタ出力 (符号付き)

LinearAsrc

入力サンプル列を線形補間して、分数比のoutput tickへ変換するASRC。

入力はinput_valid && input_readyで受け付け、内部のVeryl STD FIFOへ 一時保持する。ratioは「output 1回あたりに進む入力サンプル数」を Q(整数3bit).PHASE_WIDTHで表す。例えば96kHz入力から48kHzを作る場合は 2 << PHASE_WIDTH、96kHz入力から44.1kHzを作る場合は 96_000 / 44_100 << PHASE_WIDTH相当を設定する。

LpfShiftSigned

ビットシフトによる一次ローパスフィルタ (指数移動平均、符号付き版) 乗算器を使用せず、シフト演算のみで実装

伝達関数: y[n] = y[n-1] + (x[n] - y[n-1]) >> SHIFT

カットオフ周波数の近似: fc ≈ fs / (2π * 2^SHIFT) 例: fs=48kHz, SHIFT=8 → fc ≈ 30Hz

SHIFT値が大きいほどカットオフ周波数が低くなり、より滑らかに補間される。 SHIFTはDATA_WIDTHより大きくても問題ない。

Parameters

DATA_WIDTH u32 入出力データ幅
SHIFT u32 シフト量 (1以上)。大きいほど低いカットオフ周波数

Ports

rst input reset リセット (出力を0に初期化)
enable input bbool イネーブル信号 (trueでフィルタ更新)
x input signedlogic 入力サンプル (符号付き)
y output signedlogic フィルタ出力 (符号付き)
